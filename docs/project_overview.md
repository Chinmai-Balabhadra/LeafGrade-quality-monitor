# Oak Leaf Quality Classification and Plucking Standard Monitoring System

## Objective
Develop a computer vision system that analyzes oak leaf images and classifies their quality using deep learning.

## Planned Features
- Oak leaf quality classification
- Leaf detection and damage localization, if suitable data is available
- Plucking recommendations based on defined quality standards
- Image upload and prediction interface
- Model evaluation and performance reporting

## Technology Stack
- Python
- OpenCV
- PyTorch
- Streamlit
- Git and GitHub

## Team Responsibilities
- Member 1: Deep learning model and classification
- Member 2: Application interface and integration
- Member 3: Dataset preparation, evaluation, and detection experiments

## Dataset Status
The dataset and quality labels are still being finalized. The plucking criteria must be confirmed before recommendations are implemented.
